################################################################################
# Millennium Dawn: Modern Day Mod - Changelog
################################################################################

[GUI / Interface]
- Replaced legacy dot-based GDP ledger with 10 high-performance vector line graphs (GDP, GDP/C, Productivity, Debt, Inflation, Population, Fiscal Budget, Energy Grid, Defense Spending, Trade Balance) featuring dynamic auto-ranging axes, YoY tracking, and full 'disable_gdp_graph' game rule integration (PR #4842).
- Overhauled 10-year rolling window buffer: synchronized array shifting at Month 108 (Year 10 Jan) to position the active year at Pointer 8 (slot 96), maintaining a clean 12-month forward runway and eliminating graph clipping beyond the right border frame.
- Added 'dirty = gdp_graph_dirty_var' property bindings across all 11 scripted GUI containers, eliminating per-frame Clausewitz DOM re-evaluations and interface stutter.
- Consolidated 10 country open flags and 90 repetitive tab button handlers into a single scalar tab variable ('md_graph_tab'), reducing over 1,500 lines of scripted GUI boilerplate.
- Standardized and localized 100% of graph titles, metric headers, status indicators, and tooltips into 'localisation/english/md_submod_econ_cycle_l_english.yml' (zero hardcoded GUI strings).

[Economy / Mechanics]
- Fixed resource import valuation in international trade calculations by replacing the legacy 1/12000 divisor with the canonical constant '@resource_sale_rate_constant = 0.00298' from '00_money_system.txt', correcting a 35.76x expenditure undervaluation.
- Fixed deficit line coloring across Budget, Energy Grid, and Trade Balance: replaced normalized coordinate checks ('y1_val < 0') with raw metric evaluations ('check_variable = { v < 0 }'), ensuring fiscal deficits, energy shortages, and negative trade balances correctly render in red.
- Fixed 'on_startup' player initialization scoping: wrapped player setup inside 'every_country = { limit = { is_ai = no } ... }' to eliminate silent global-scope execution drops.
- Integrated full 'disable_gdp_graph' game rule enforcement across open button visibility, monthly data sampling, array shifts, and GUI triggers.

[Optimization & Performance]
- Deduplicated 19 separate line-drawing loops into shared Clausewitz-native math effect 'md_calc_segment_math'.
- Centralized dynamic axis range calculations into unified effects 'md_calc_standard_axis' and 'md_apply_axis_zoom_and_step'.
- Implemented lazy coordinate generation in 'on_monthly': screen rendering math now executes exclusively for the active open tab rather than evaluating all 10 tabs simultaneously.
- Purged 7 unused shaders ('dial.shader', 'half_dial.shader', 'radar.shader', 'radar5/*.shader') and 9 unreferenced legacy DDS texture files.
- Removed legacy save-migration heal effects ('md_submod_heal_corrupted_arrays') that previously distorted legitimate economic downturns.
- Enforced 100% Clausewitz parser compliance: eliminated unsupported tokens ('>=') in favor of standard 'NOT < 0' checks, verified zero syntax errors and 100% bracket parity.
