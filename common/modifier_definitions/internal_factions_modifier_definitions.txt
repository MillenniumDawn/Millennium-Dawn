# Information:
# The following set of modifiers for each internal faction are general purpose modifiers for interacting with the internal faction system
# for national content.
# -----
# Examples:
# if_<faction>_monthly_opinion - Improves a factions opinion per month by x amount (applies whether or not opinion decay is enabled)
# if_<faction>_minimum_opinion - Raises the decay floor (50) and the hard floor (0) for the faction's opinion
# if_<faction>_maximum_opinion - Changes the maximum opinion for a faction (100 by default, never above 100)
