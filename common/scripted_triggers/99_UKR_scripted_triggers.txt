# Stored equipment sales (UKR_reactivate_sov_category): can the buyer place this order? Checked in the buyer's scope from the Ukrainian sale missions
# and decisions (UKR_storage_sale_*), so ROOT is Ukraine. The same thresholds apply to player and AI buyers.
# Indonesia needs 5 less opinion for one deal after it bought the other (BTR-50 / PT-76B).
# Influence: 2% for cheap equipment, 3% for fighters, the 2K11 and the S-125, 5% for the S-75, bombers and the MiG-25.
# Smaller orders need none, except the smaller 2K11 order (1%).
# Our influence over a buyer of stored equipment (buyer scope, ROOT = Ukraine). MD's generic checks start at 5%.
# Each gate sits half a step below its nominal percent: change_influence_percentage scales a +1 step by Ukraine's influence
# modifiers and the buyer's foreign_influence_defense_modifier, so one step can realize less than 1%.
UKR_storage_influence_1 = {
	any_of = {
		array = influence_array
		value = v
		index = i
		var:v = { tag = ROOT }
		check_variable = { influence_array_val^i > 0.499 }
	}
}
