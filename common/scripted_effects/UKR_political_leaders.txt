#  2) if every matching leader was already used (repeat win), take the LAST leader whose window matches today.
# The windows are copied 1:1 from the party-name windows in
# common/scripted_localisation/00_MD_politicsview_scripted_localisation.txt (UKR.<ideology>_<year> keys), so the
# party shown in the politics view and its leader cannot drift apart. If a name window changes there, change it here too.
